# 📂 WAMFF — Where are my F*cking Files
WAMFF (Where are my Fucking Files) is a sleek and modern desktop application built to help you keep track of your files with categories, tags, and a powerful search interface — because let’s be honest, we’ve all yelled "where the fuck did I put that file?" at some point.

## ❓ What is WAMFF?
WAMFF is a focused file organization tool built for people who deal with lots of documents (like PDFs, spreadsheets, and notes) and need a simple, centralized place to tag, categorize, and find them quickly. It’s built with usability in mind — combining a clean interface with practical features

## 🚫 What WAMFF is not

WAMFF is not a replacement for Windows File Explorer or a full-blown file manager. It doesn’t aim to:
- Manage your entire file system
- Replace folder-based navigation
- Provide thumbnails for every file type
- Handle system-level file operations (like cut/copy/move/delete outside of its scope)
  
Instead, it’s here to complement your file workflow — focusing solely on managing your important documents more intelligently, not every single file on your PC.

## 🚀 Features
- 🗂️ Organize with Ease: Categorize your files into custom-defined groups.
- 🏷️ Tag Everything: Apply multiple tags to each file for lightning-fast filtering.
- 🔍 Search Bar with Live Filter: Instantly find what you're looking for with a top-bar search.
- 📑 File Metadata at a Glance: View file size, type, extension, creation date, and last modified date.
- 📁 Support for PDFs and Excel Files: Easily manage common document types with proper previews.
- ✅ Modern and Minimal UI: Clean, dark-themed interface designed for productivity and aesthetics.
